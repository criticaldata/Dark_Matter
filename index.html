The Dark Matter of Clinical Data

A lab value only enters the health record if someone orders the test. We prove that observational EHR data alone cannot separate a patient's biology from that care process, and we show what can.

The problem

Every empty cell is a decision

Models trained on electronic health records learn from what was measured. But a measurement exists only because a clinician ordered it, and ordering depends on suspicion, local habits and hospital policy.

So every representation learned from the EHR mixes the patient with the care process. The paper asks whether observational data can undo that mixing, within one dataset or by comparing hospitals, and proves where the answer is no.

Explore 3 · Theorem 1(ii)–(iii), Corollary 1

Code "not measured" as −1

The usual alternative is to write a code for untested patients. Pick one. A code that cannot be mistaken for a real result turns the value into a record of the ordering decision, and the decomposition of ordering is then fixed in advance. A fill-in that looks like a real result just moves the ordering information into the fill-in rule.

Add a test drawn for every patient

Routine tests, such as a basic metabolic panel at every admission, have no ordering gate. If one of them measures the true state, it breaks the tie from Explore 1. Choose which world is secretly true, then turn the routine test on. This uses the hospitals you set up in Explore 1.

The hidden truth
Measurement

The routine test here measures the true state exactly (V = Z*), the strongest case. Proposition 5 shows that two imperfect routine tests with independent errors also work for binary physiology, as long as the case mix differs between sites. These results rest on assumptions about the assays, not on the data alone.

For researchers

What to do differently

Four changes to how cross-site analyses of EHR models are run and reported.

Report a joint hypothesis

A cross-site comparison tests shared biology and a site-stable representation together. Report it that way, not as proof of shared biology.

Run the sensitivity analysis

State the representation error rate you assume and the gap it can explain, as in Explore 1.

Anchor on routine tests

Where a test is drawn for everyone, use it as a reference standard to calibrate the model's errors.

Say how unmeasured values were encoded

Missingness indicators are useful predictors, but they cannot separate patient from process. Use interventional variation in who gets tested where you can.
